# Bachelorarbeit – Career Counseling Chatbots

## Projektbeschreibung

Dieses Projekt untersucht das Erfolgspotential von Career Counseling Chatbots aus Sicht von Stellensuchenden. Das Erfolgspotenzial wird durch das Nutzungspotenzial operationalisiert, das anhand zweier Dimensionen untersucht wurde: der Nutzungsakzeptanz sowie des erwarteten funktionalen Nutzens. 

Im Projekt wurden Umfragedaten analysiert und statistische Auswertungen sowie Visualisierungen mit Python erstellt.

## Verwendete Technologien

- Python
- Pandas
- SciPy
- Pingouin
- OpenPyXL
- Matplotlib
- VS Code
